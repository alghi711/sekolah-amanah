# Admin penerbitan Sekolah Amanah

**Goal:** Admin login, menulis berita/artikel, mengunggah foto, dan menerbitkannya langsung di sekolahamanah.sch.id.

**Architecture:** PHP 8 pada Hostinger, sesi server, akun tunggal Admin dengan hash password di luar public_html. Penyimpanan JSON privat dengan penguncian dan penulisan atomik agar tidak memerlukan koneksi MySQL yang saat ini belum aktif. Konten lama dipertahankan; beranda dan profil membaca sumber yang sama. Mode statis Wasmer tetap memakai snapshot.

**User direction:** Lanjut mengerjakan admin; penerbitan langsung diasumsikan dari permintaan awal dan diumumkan sebelum pengerjaan. Nama akun sesuai permintaan; password asli tidak masuk repository atau paket publik.

## Constraints

- Pertahankan 30 artikel yang sudah tayang, foto, desain, dan perilaku kartu berita.
- Tindakan menulis memerlukan sesi admin dan token CSRF. Login dibatasi per alamat IP; sesi berakhir setelah tidak aktif.
- Hanya JPEG, PNG, WebP valid, maksimal 8 MB dan 30 megapiksel. Nama acak; unggahan tidak boleh dieksekusi sebagai skrip.
- Isian judul, isi, tanggal, jenjang, jenis berita/artikel dan kategori divalidasi di server. Isi disimpan sebagai teks, bukan HTML bebas.
- Penyimpanan dan kredensial di folder amanah-private sejajar public_html; setiap penerbitan mencadangkan konten sebelumnya.
- Gunakan gaya Amanah yang sudah ada, form berlabel dan kontrol nyaman untuk ponsel. Pengguna memilih antislop saat pengerjaan.

**Design read:** warna hijau, font Jakarta, tepian tegas dan bayangan pendek dari website Amanah. Form mendapat ruang utama; daftar tulisan mengikuti di bawah. ENERGY 1 / RHYTHM 2 / MOTION 0. Tidak ada aset visual baru; logo dan font memakai berkas sekolah yang sudah tersedia.

## Review focus

- Akses tanpa login, CSRF salah, percobaan login berulang, serta sesi yang kedaluwarsa.
- Berkas skrip yang berpura-pura menjadi foto, ukuran berlebih, dan nama berkas berbahaya.
- Konten berisi tanda kutip, tag HTML, Unicode, paragraf panjang; semuanya ditampilkan sebagai teks.
- Permintaan penerbitan bersamaan atau diulang tidak menimpa artikel lain atau menerbitkan duplikat.
- Store rusak atau tidak dapat ditulis tidak boleh menghapus konten atau melaporkan sukses.
